# Netflix UI Clone

This is a Netflix UI clone made by me using **Flutter** and **Dart**.

This project is mainly made to practice Flutter UI design and to create a movie streaming app style interface. It is only a **UI project** and does not provide real movie or TV show streaming.

## About the Project

I created this project to practice building different screens in Flutter and to make the UI look similar to a modern streaming application.

The project contains screens for:

- Welcome screen
- Login
- Sign Up
- Home
- New & Hot
- Downloads
- Profile
- Search
- Notifications
- Forgot Password
- Reset Password

## Screens

### Welcome Screen

The welcome screen contains the Netflix title, a background image, and buttons for Login and Sign In.

### Sign Up

The Sign Up screen contains fields for:

- Email
- Password
- Confirm Password

It also contains a Sign Up button and social login icons.

### Login

The Login screen contains:

- Email
- Password
- Forgot Password
- Login button
- Social login icons

### Home

The home screen shows a movie/series banner with buttons such as Play and Info. It also contains a **Trending Now** section and bottom navigation.

### New & Hot

This screen shows different movie and series posters in a grid layout.

### Downloads

The Downloads screen shows downloaded movies with their names and file sizes.

### Profile

The Profile screen contains the user profile and options such as:

- Account Settings
- Privacy
- Language
- Help & Support
- Log Out

### Search

The Search screen allows the user to search for movie and series names through the UI.

### Notifications

The Notifications screen displays movie and series related notifications.

### Forgot Password

The Forgot Password screen asks for the registered email address before continuing.

### Reset Password

The Reset Password screen contains fields for entering and confirming a new password.

## Technology Used

- Flutter
- Dart
- Android Studio

## Project Type

**UI / Frontend Project**

This project is focused on the Flutter UI. It does not include a real streaming service or Netflix's actual backend.
